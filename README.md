# Техническое задание: сервис управления задачами

## Структура проекта

```
.
├── cmd/
│   └── main.go         # Точка входа
├── internal/
├── go.mod              # Зависимости Go-модуля
└── .env                # Переменные окружения
```

## Запуск проекта

### Поднять сервис в docker контейнере
```bash
docker-compose up
```
